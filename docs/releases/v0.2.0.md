Dotwear now ships for **React Native** and **Flutter**, with the same icons, tokens, pixel font and four core components as the web and iOS.

### Packages

| Platform | Icons only | Icons + UI |
|---|---|---|
| Web (npm) | `@dotwear/icons@0.2.0` | `@dotwear/web@0.2.0` |
| iOS (Swift Package Manager) | `DotwearIcons` | `Dotwear` |
| React Native (npm) — new | `@dotwear/react-native-icons@0.2.0` | `@dotwear/react-native@0.2.0` |
| Flutter (pub.dev) — new | `dotwear_icons` 0.2.0 | `dotwear` 0.2.0 |

```sh
npm install @dotwear/react-native      # React Native
flutter pub add dotwear material_ui    # Flutter 3.47+
```

### What's new

- **React Native:** `DotwearIcon` draws icons with plain views, so no native modules are needed. Each cell is rounded to whole device pixels, so edges stay crisp on fractional densities such as 2.625×. The package also has `DotwearButton`, `DotwearTextField`, `DotwearToggle` and `DotwearCard`, built on `Pressable` and `TextInput`, plus `DotwearTheme`, `useDotwear()` and the bundled DotGothic16 font (`useFonts(dotwearFonts)` with Expo).
- **Flutter:** `DotwearIcon(DotwearIcons.save)`, `DotwearThemeData` (a `ThemeExtension`; `toThemeData()` sets up colors, font and icon color), and the same four components on standard `TextButton` and `TextField`. Built on `material_ui`.
- **Palettes as values:** `@dotwear/icons` exports `palettes` (for example `palettes["retro-green"]`), for places without CSS variables.
- Docs: every code example now has React Native and Flutter tabs.

Docs: https://dotwear.dev

Swift and Android packages are unchanged apart from the version number. Android (Maven Central) is not published yet.
