First public release of Dotwear: pixel-art icons and UI styles for everyday apps, generated from one source for the web and iOS.

### Packages

| Platform | Icons only | Icons + UI |
|---|---|---|
| Web (npm) | `@dotwear/icons@0.1.0` | `@dotwear/web@0.1.0` |
| iOS (Swift Package Manager) | `DotwearIcons` | `Dotwear` |

```sh
npm install @dotwear/web
```

Swift Package Manager: add `https://github.com/dotwear-dev/dotwear-swift` with version `0.1.0`.

### What's included

- 60 icons on a 16 × 16 grid, rendered only at whole-number scales so edges never blur.
- Components: Button, TextField, Card and Toggle — React components on the web, `ButtonStyle` / `TextFieldStyle` / `ToggleStyle` on SwiftUI. Platform accessibility (VoiceOver, Dynamic Type, keyboard) keeps working.
- Design tokens (colors, pixel unit, typography) as CSS variables, TypeScript constants and Swift values.
- Bundled pixel font: DotGothic16 (SIL OFL 1.1).

Docs: https://dotwear.dev

Android (Maven Central) is not published yet.
